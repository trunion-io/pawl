# PAWL-001 — Edit-time claim capture

**Status:** delivered · **Module:** `pawl.claimlog`, `pawl.models`

## Stakeholders

| Role | Signature |
|---|---|
| Product | *unsigned — written after the code* |
| NFR (SRE) | *unsigned* |

## Context

Claims must be recorded at the moment of the edit. A claim assembled at PR time
is a model re-reading its own diff. Rejected alternatives in particular cannot
be recovered afterwards, because the diff holds no trace of the path not taken.

## Acceptance criteria

**AC1** — When an agent records a claim, the system shall capture the claim
text, path, line range, kind, and a content fingerprint of the referenced span
taken from the working tree.
`checkable: yes` → `test:trunion.io/pawl/internal/e2e.TestVerifiedClaimCollapsesItsHunk`

**AC2** — The system shall append claims to a log and shall never rewrite or
delete an existing entry.
`checkable: partially` — append-only writes use `O_APPEND`; no test asserts the
absence of a rewrite path.

**AC3** — When concurrent pod members record claims against the same repository,
the system shall not interleave partial records.
`checkable: no` — relies on `O_APPEND` atomicity below `PIPE_BUF`. Untested.
**This is a known gap, not a solved problem.**

**AC4** — If a claim names a file that does not exist, then the system shall
refuse the claim rather than record it.
`checkable: yes` → `test:trunion.io/pawl/internal/e2e.TestClaimAgainstAMissingFileIsRefused`

**AC5** — The system shall record the author role (agent, expert, client) on
every claim.
`checkable: yes` → `test:trunion.io/pawl/internal/e2e.TestAttestationShape`

## Non-functional

- **Latency** — a claim write sits in the agent's edit loop and must not be
  perceptible. File append only; no network, no lock.
- **Durability** — the log lives in the working tree and is excluded from the
  changeset it describes. Loss of the log before commit loses the trail.

## Out of scope

- Claim editing or retraction. An append-only log with a later superseding entry
  is the intended mechanism; not yet designed.
- Any claim generated by inspecting a diff. Explicitly forbidden by C-2.
